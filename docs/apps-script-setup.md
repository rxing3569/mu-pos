# 月份訂單 Apps Script v3 設定

## v6 菜單備份部署

前端菜單設定與冷熱分價備份需要 Apps Script v6。保留 `SPREADSHEET_ID` 與 `POS_ACCESS_KEY`，將本專案 `apps-script/Code.gs` 全文更新至原 Apps Script 專案，建立新版本並更新原部署。開啟原 `/exec` 應回傳 `version:6`。首次成功備份菜單時自動建立「菜單」分頁；既有菜單分頁會增加「冷熱選項」欄。原有每月訂單分頁與 `_SyncLog` 保留。前端網站也須重新部署靜態輸出。

1. 保留既有指令碼屬性 SPREADSHEET_ID 與 POS_ACCESS_KEY。
2. 將 apps-script/Code.gs 全文更新至 Apps Script，儲存並執行 setup。時區為 Asia/Taipei。
3. 管理部署 → 編輯原部署 → 選新版本 → 部署。執行身分「我」、存取者「任何人」。部署 URL 不變。
4. 開啟 /exec 應顯示 version:3，前端連線帳務後測試一筆訂單。

新版本不使用 Menu、Orders、Adjustments、Expenses 四張工作表，也不自動刪除舊表；未有正式資料，不執行轉移。新訂單首次寫入時自動建立 YYYY-MM 分頁，一張訂單一列。UUID 固定；跨月修改維持原月份。

API 全部 POST text/plain JSON body，帶 key。action 支援 list（month）、get（id）、create（id,data）、update（id,version,data）、refund（id,version,lineId,qty,reason）、delete（id,version）。不再帶 table。

update 直接覆寫品項、桌號、備註，日期固定。refund 扣減當前數量，保留最後原因與時間；全退保留零元訂單。delete 實體刪除整列，無法由系統復原。所有金額由伺服端重新計算。跨月份 UUID 查找與版本檢查在寫入鎖內執行。

新增 UUID 在首次建單前產生，逾時沿用原 UUID。版本衝突請重新整理再編輯。修改、退單、刪除若結果不明，須先回查 UUID，不能盲目重送。

只固定公開部署 URL；存取密碼由使用者輸入，不放在原始碼或網址。資料量大時目前逐月掃描 UUID 可能需要改善索引。單台主裝置使用，沒有個別員工權限。真實跨來源連線與權限仍須部署後驗證。

## 每日流水號

更新 Code.gs 後先執行 setup，再更新原部署至新版本。setup 會在既有月份分頁第 13 欄增加流水訂單號，依日期補齊沒有號碼的舊單，不變更 UUID。執行期間請暫停點餐。顯示號碼格式 YYYYMMDD-001，台北時間每日重置，刪除不重用，失敗寫入可能跳號；唯一識別仍為 UUID。指令碼屬性 DAILY_SEQ_* 是每日計數器，不要手動清除。

## v4：本機先存，手動同步

將新版 Code.gs 貼入，執行 setup 並更新原部署的新版本，/exec 應顯示 version:4。保留兩個原指令碼屬性。首次同步會自動建立隱藏的 _SyncLog，請勿刪除此紀錄表；它用來辨識已處理的操作。正式使用前先備份試算表。

現在新增、編輯、退單、刪除存在 IndexedDB；操作成功只代表本機保存成功。訂單頁的同步按鈕才上傳佇列，成功後才移除對應待同步操作。連線密碼仍只放記憶體。不同網站來源（localhost、IP、正式網域）不共用本機資料，換網址或換機前先同步或匯出備份。

同步每批最多10筆，前端依100,000 bytes拆批，伺服端限制請求大小及約15秒的批次處理時間。已成功結果逐筆確認，未處理或失敗的操作仍保留。資料以完整快照送出，本機覆蓋同UUID的雲端紀錄；沒有待同步修改的訂單才會被雲端內容刷新。刪除是雲端實體刪除，但本機會保留待同步刪除操作至成功為止。一般有效請求設每分鐘120次粗略應用層限制；此機制不能防止公開端點遭拒絕服務。

訂單頁可備份／還原JSON。還原以保留現有待同步資料為優先。流水號碰撞時，使用「重編待同步號碼」讀取雲端最高號，再同步。未同步訂單可能因瀏覽器資料被清除而遺失，請每日同步並備份。

月份首次下載以每頁200筆讀取，後續以同步紀錄游標增量讀取；最近查閱月份以外的已同步快取會清除，未同步資料保留。資料未完整下載時介面有提示。舊版待確認結單會先保留並鎖住點餐，連線時以UUID回查：雲端已有則採已確認結果，沒有則轉成本機待同步訂單。回查失敗時不清除原資料。

安全修正包括文字公式防護、金額與數量驗證、大小限制與錯誤白名單。密碼持有人仍具備全部帳務權限，不能防止其蓄意竄改；也不具備個別店員權限。配額參考 https://developers.google.com/apps-script/guides/services/quotas 。套件漏洞掃描因DNS失敗未完成。真實瀏覽器IndexedDB、跨來源及斷線測試仍需在部署後確認。
